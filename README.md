# ShEC UMS

**Full title:** Design and Development of ShEC UMS: A Modular Cross-Platform University Management System Using .NET MAUI and Clean Architecture

## Overview

ShEC UMS is a university management system being developed initially for Shyamoli Engineering College, with a design intended to support future expansion to multiple institutions.

## Technology Stack

- .NET 10
- C#
- ASP.NET Core Web API
- .NET MAUI
- Clean Architecture
- Git

## Repository Structure

- `src/ShEC.UMS.Api` — Backend API
- `src/ShEC.UMS.App` — Cross-platform client
- `tests` — Automated tests
- `docs` — Project documentation
